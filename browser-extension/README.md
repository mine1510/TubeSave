# TubeSave — расширение для Chrome / Edge / Яндекс.Браузер

Кнопки на страницах отправляют ссылку в TubeSave **без копирования**.

## Что умеет

| Сайт | Кнопка |
|------|--------|
| YouTube / **Shorts** | `Скачать видео` на обычных роликах; синяя кнопка **Скачать** над лайком в Shorts |
| VK / **клипы** | `TubeSave Клип` (+ плавающая ↓ Клип) |
| **Яндекс.Музыка** | `TubeSave` / ↓ Музыка (скачивает **аудио**) |
| Остальные (PornHub, Iwara, Rule34) | Иконка расширения на панели |

## Установка

1. Запустите **TubeSave**.
2. Страница расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Яндекс.Браузер: `browser://extensions`
3. **Режим разработчика** → **Загрузить распакованное** → эта папка.
4. Если расширение уже стояло — нажмите **Обновить** на карточке TubeSave.

Приложение **не обязательно держать открытым**. По кнопке «Скачать» расширение само запускает TubeSave (браузер может спросить «Открыть TubeSave?» — согласитесь). Один раз откройте приложение, чтобы зарегистрировать протокол.

## Автообновление

- Раз в ~6 часов плагин читает `update.json` с GitHub.
- Если версия новее и TubeSave запущен — файлы плагина обновляются через мост, затем `chrome.runtime.reload()`.
- Если приложение закрыто — откроется страница релизов.
