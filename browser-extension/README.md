# TubeSave — расширение для Chrome / Edge / Яндекс.Браузер

Кнопки на страницах отправляют ссылку в TubeSave **без копирования**.

## Что умеет

| Сайт | Кнопка |
|------|--------|
| YouTube / **Shorts** | `Скачать видео` на обычных роликах; синяя кнопка **Скачать** над лайком в Shorts |
| VK / **клипы** | `TubeSave Клип` (+ плавающая ↓ Клип) |
| **Яндекс.Музыка** | `TubeSave` / ↓ Музыка (скачивает **аудио**) |
| Остальные (PornHub, Iwara, Rule34) | Иконка расширения на панели |

## Установка

1. Запустите **TubeSave**.
2. Страница расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Яндекс.Браузер: `browser://extensions`
3. **Режим разработчика** → **Загрузить распакованное** → эта папка.
4. Если расширение уже стояло — нажмите **Обновить** на карточке TubeSave.

### Яндекс.Браузер

Расширения не из [Chrome Web Store](https://chrome.google.com/webstore) или Opera Add-ons браузер **отключает при каждом перезапуске** ([документация Яндекса](https://yandex.com/support/browser/en/security/check-extensions)). После запуска откройте `browser://extensions` и нажмите **Включить** на TubeSave — папку заново выбирать не нужно.

Постоянная установка без этого: расширение в Chrome Web Store, или для разработки — [Яндекс.Браузер Beta](https://browser.yandex.com/beta/).

Приложение **не обязательно держать открытым**. По кнопке «Скачать» расширение само запускает TubeSave (браузер может спросить «Открыть TubeSave?» — согласитесь). Один раз откройте приложение, чтобы зарегистрировать протокол.

## Автообновление

- Приложение само проверяет новую версию при запуске и раз в несколько часов.
- Плагин тоже проверяет обновления. Если TubeSave закрыт — он запускает программу и ставит обновление сам.
- Браузер GitHub не открывает: архив скачивается и ставится в фоне.
- После обновления приложения TubeSave перезапускается; расширение перезагружается само.
