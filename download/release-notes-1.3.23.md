Исправлена ошибка «HTTP Error 413: Request Entity Too Large» при скачивании с Яндекс.Музыки.

Расширение больше не передаёт все cookies Яндекса — только сессию для входа. Приложение получает OAuth-токен и не отправляет огромный заголовок Cookie в API. Также: копирование из журнала работает на русской раскладке (Ctrl+С).
